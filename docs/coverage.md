Первые пять категорий относятся ко всем сохранённым строкам, **не только последним подписанным версиям**. Последняя строка дополнительно учитывает версии договора/позиции, статусы, удаление, валюту, положительные цену/количество и наличие кода/единицы. Счётчики снимались последовательно при работающем загрузчике, поэтому небольшой рост между измерениями возможен.

Предыдущая формулировка «96 279 пригодно для аналитики» была неверной: это была только проверка связи с активным планом. Сам признак `active=false` исторического плана не является отдельным фильтром подписанной договорной позиции в текущем analytics.snapshot; `deleted=true` является. Нельзя подменять один счётчик другим.
